# 介绍
收集各种页面效果和技巧的静态示例。

**本目录 `hexo-blog/hexo/source/effects/` 已经是唯一来源**，随博客一起发布在
https://strugglexiang.github.io/effects/ 。
原来的独立仓库 `strugglexiang/page_effects` 已停止维护，仅作历史归档；
新增或修改示例请直接在本目录操作，然后运行 `hexo/deploy.cmd`。
